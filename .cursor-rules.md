# Project rules

- Preserve all entries and repetitions in `src/data/pairs.ts`.
- Never alter the canonical sequence without explicit product-owner instruction.
- The only authorised list correction is `cloud — crowd`.
- Use TypeScript strictly; avoid `any`.
- Keep components small and focused.
- Do not introduce paid APIs.
- Do not upload student audio.
- Do not claim browser transcription is pronunciation scoring.
- Keep browser-specific APIs inside typed hooks or adapters.
- Run lint and production build after each implementation stage.
- Explain any unavoidable browser limitation plainly.
